
# Mangata & Gallo - Luxury Jewelry Website

# Live demo Link
https://g-g-landing-page.vercel.app/

A responsive e-commerce website for a high-end jewelry boutique specializing in custom engagement rings and wedding jewelry.

## Features

- **Responsive Design**: Adapts seamlessly from mobile to desktop
- **Interactive Elements**:
  - Promotional video background
  - Smooth scrolling navigation
  - Mobile-friendly hamburger menu
- **Modern Layout**:
  - CSS Grid for main content structure
  - Flexbox for component organization
- **Performance Optimized**:
  - Compressed images
  - Efficient CSS delivery

## Technologies Used

- HTML5 semantic markup
- CSS3 (Grid, Flexbox, animations)
- Vanilla JavaScript for interactivity
- Font Awesome icons
- Google Fonts (Smooch Sans, Lexend Giga)
